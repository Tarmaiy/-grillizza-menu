Grillizza Admin

1) Upload this whole package to the ROOT of the GitHub repository.
2) Open: https://tarmay.github.io/-grillizza-menu/admin.html
3) Edit Kurdish/Arabic/English/Persian names, price, and each photo.
4) Press Save Draft while working.
5) Press Export Menu. The browser downloads Grillizza_MENU_UPDATED.html.
6) Upload that new HTML to the repository and replace index.html.

Important: this version lets you manage the menu yourself without changing code. The Export step makes the changes permanent on the public menu. No online ordering or payment is included.
